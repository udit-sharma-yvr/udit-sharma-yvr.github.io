# Udit Sharma — Portfolio website

A responsive, static portfolio site built with HTML, CSS, and a little JavaScript. It is ready to publish with GitHub Pages.

## Files
- `index.html` — page content and sections
- `styles.css` — responsive styling
- `script.js` — mobile navigation and footer year

## Publish with GitHub Pages

1. Create a GitHub repository named **`udit-sharma-nz.github.io`** (replace `udit-sharma-nz` with your GitHub username if different).
2. Upload `index.html`, `styles.css`, and `script.js` to the repository's root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. GitHub will publish the site at `https://YOUR-USERNAME.github.io/`. It can take a few minutes.

If you prefer a project repository instead, use any repository name and select `main` / `/(root)` in Pages. The URL will be `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Before publishing
- Confirm your preferred public phone number and email. Your phone number is intentionally not shown on the page; the contact section uses email and LinkedIn.
- Add a downloadable PDF resume if you want one (for example, place `resume.pdf` in the repository and add a link in the hero section).
- Review all metrics and wording for accuracy and ensure your current employer's confidentiality rules allow public discussion of the work.
- Consider adding 2–3 public, non-confidential technical projects or engineering write-ups. Do not publish internal architecture, code, incident details, or proprietary information.
